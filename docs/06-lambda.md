# 06 Lambda 表达式

lambda 用中括号 `[...]` 定义，等价于一个只有 `apply` 方法的对象，即：

```ooc
[x -> x + 1]   ≡   { apply(x) { x + 1 } }
```

调用方式与普通消息一致：`f apply 参数...`。

## 带参 lambda（`->` 分隔参数与函数体）

```ooc
f = [x -> x + 1];
f apply 41        // 42
```

## 多参数（逗号分割）

```ooc
add = [a, b -> a + b];
add apply 20 22   // 42
```

参数可带类型注解：

```ooc
add = [a: number, b: number -> a + b];
```

## 无参 lambda（省略 `->`）

```ooc
f = [42];         // 无参 lambda，返回 42
f apply           // 42

n = 2;
g = [n * 21];     // 函数体以标识符开头，无参数时是函数体而非参数
g apply           // 42
```

## 多语句函数体（与方法体一致）

```ooc
f = [x -> y = x + 1; y * 2];   // 分号分割多条语句，最后一条为返回值
f apply 20        // 42
```

## 闭包捕获

```ooc
n = 1;
f = [x -> x + n]; // 捕获定义时的外部变量
f apply 41        // 42
```

## 作为消息参数

```ooc
obj = { call(f) => f apply 42 };
obj call [x -> x * 2]   // 84
```

## 与对象 apply 方法的区别

lambda 是 `{ apply(...) { ... } }` 的语法糖，二者可互换：

```ooc
// 下面两种写法等价
f1 = [x -> x + 1];
f2 = { apply(x) { x + 1 } };

f1 apply 41   // 42
f2 apply 41   // 42
```

**特性：**

- 与 `{ apply(...) { ... } }` 语义完全相同，通过 `apply` 消息调用
- 参数用逗号分割，用 `->` 与函数体分隔
- 函数体可以是单个表达式，也可以是分号分割的多条语句（与方法体一致）
- 自动捕获定义时的闭包环境
- 类型上记为函数类型，参数类型注解参与类型检查
