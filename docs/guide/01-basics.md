# 01 基础语法

## 变量

```ooc
x = 42           // 数字
name = 'ooc'     // 字符串（单引号）
flag = true      // 布尔
nothing = nil    // 空值
```

语句用 `;` 分隔。整个文件的最后一条表达式作为运行结果。

绑定等价 JS 的 `const`：**同层作用域不允许同名重新声明**（顶层、方法体、绑定块 `@{…}`、lambda 各是一层作用域；`#guard` / `#else` 分支不另开作用域）。所以没有“重新赋值”，要变更数据用 `storage ref`、数组 `toSpliced` 等不可变/引用手法。不同层可以同名（方法内可遮蔽顶层）。

## 基本类型

- 数字：`42`、`3.14`
- 字符串：`'hi'`（只能单引号）
- 布尔：`true` / `false`
- 空值：`nil`

## 运算符

```ooc
1 + 2      // 3，数字加法；对字符串是拼接
7 - 3      // 4
6 * 4      // 24
7 % 3      // 1，取模
10 > 5     // true；>= <= < 同理
10 == 10   // true；!= 同理
1 && 0     // 0；|| 同理
```

注意：`//` 是注释符号，不是除法；除法用消息形式 `12 div 3`（`div` 是消息名）。`/` 是级联符（结果继续发消息）。

## 消息调用

一切都是消息，写法是 `接收者 消息名 参数...`：

```ooc
'abcdef' slice 1 3    // 'bc'，调用字符串方法
'abc' + 'def'         // 'abcdef'
```

消息名、参数之间用空格分隔，没有括号。名字位置的 `$` 是「直接调用」（`f $ x` 调用 `f`，调用 lambda 时常用）；定义也写 `$`（`{ $(x) => … }`）。`$` 还能当中缀运算符，消息链后直接接 `$` 即直接调用，无需前置 `/`（`close get $ false` ≡ `close get / $ false`），右侧可接 0~N 个实参（`x get $` 零参、`h get $ 1 2 3` 三参）。

## JS 对象属性

自定义对象（`{ ... }`）的成员按形状分流：常量绑定（`x = 值`）——纯字面量是数据属性、计算式是 getter，取值本身；方法（`=>` / `{ }` 方法体，含零参）编译成带内部标记的函数，**发消息才执行**（`obj f`，JS 侧 `.f()` 调用）。返回函数值（lambda）时原样返回，不会被隐式调用。纯字面量常量成员必须直接写绑定（`kind = 'circle'`，否则 validator 报错）。JS 原生对象的属性则直接读取：

```ooc
'abcdef' length     // 6，读取 JS 属性
Math PI             // 3.14159...
```

对 JS 对象发消息的规则：own 属性优先——访问器（getter/setter）单次读取、结果原样返回（带 setter 时实参写入）；数据属性是函数就执行，非函数则不带参数读取、带参数且可写时写入（仅限已存在的属性）；原型链方法照常执行；都不存在时抛「没有定义该方法」。需要拦截未知消息的对象（如 merge 的委托包装）要显式包一层兜底 Proxy：`js proxy 对象 [name, ...args => 转发]`，handler 即为接收方。

## 项目配置

`config.ooc` 是**真正的 OOC 文件**，由解释器执行，**最后一条表达式**返回配置对象。支持变量、注释等完整 OOC 语法：

```ooc
// config.ooc — 这是一个真正的 OOC 文件
// 注释、变量、所有 OOC 语法都可用
// 最后一条表达式返回配置对象

{ diagnostics = {
    typeMismatch = 'warning',      // 类型不匹配：警告
    callArgsMismatch = 'error',    // 参数数量不匹配：错误
    noImplicitAny = 'off',         // 隐式 any：隐藏
} }
```

三级控制：`off`（隐藏）、`warning`（警告）、`error`（错误）。

> CLI 和 LSP/IDE 环境均使用解释器执行 `config.ooc`，支持完整 OOC 语法。

快速初始化：

```bash
ooc init    # 在当前目录生成 config.ooc 模板
```
