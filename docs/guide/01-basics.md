# 01 基础语法

## 变量

```ooc
x = 42           // 数字
name = 'ooc'     // 字符串（单引号）
flag = true      // 布尔
nothing = nil    // 空值
x = 99           // 可以重新赋值
```

语句用 `;` 分隔。整个文件的最后一条表达式作为运行结果。

## 基本类型

- 数字：`42`、`3.14`
- 字符串：`'hi'`（只能单引号）
- 布尔：`true` / `false`
- 空值：`nil`

## 运算符

```ooc
1 + 2      // 3，数字加法；对字符串是拼接
7 - 3      // 4
6 * 4      // 24
7 % 3      // 1，取模
10 > 5     // true；>= <= < 同理
10 == 10   // true；!= 同理
1 && 0     // 0；|| 同理
```

注意：`//` 是注释符号，不是除法；除法用 `/`：`12 / 3`（中缀运算符，优先级与加减相同）。

## 消息调用

一切都是消息，写法是 `接收者 消息名 参数...`：

```ooc
'abcdef' slice 1 3    // 'bc'，调用字符串方法
'abc' + 'def'         // 'abcdef'
```

消息名、参数之间用空格分隔，没有括号。

## JS 对象属性

自定义对象（`{ ... }`）的成员都是方法：绑定（`x = 值`）也是方法函数，发消息时返回缓存值，如 `obj cached`。JS 原生对象的属性则直接读取：

```ooc
'abcdef' length     // 6，读取 JS 属性
Math PI             // 3.14159...
```

对 JS 对象发消息的规则：值是可调用方法就执行；是属性则不带参数读取、带参数写入（仅限已存在的属性）；方法、属性都不存在时走 `methodNotFound`。

## 注释

```ooc
// 单行注释
/* 多行
   注释 */
```

## 项目配置

`config.ooc` 是**真正的 OOC 文件**，由解释器执行，**最后一条表达式**返回配置对象。支持变量、注释等完整 OOC 语法：

```ooc
// config.ooc — 这是一个真正的 OOC 文件
// 注释、变量、所有 OOC 语法都可用
// 最后一条表达式返回配置对象

{ diagnostics = {
    typeMismatch = 'warning',      // 类型不匹配：警告
    callArgsMismatch = 'error',    // 参数数量不匹配：错误
    noImplicitAny = 'off',         // 隐式 any：隐藏
} }
```

三级控制：`off`（隐藏）、`warning`（警告）、`error`（错误）。

> CLI 和 LSP/IDE 环境均使用解释器执行 `config.ooc`，支持完整 OOC 语法。

快速初始化：

```bash
ooc init    # 在当前目录生成 config.ooc 模板
```
