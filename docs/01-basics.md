# 01 基础语法

## 变量

```ooc
x = 42           // 数字
name = 'ooc'     // 字符串（单引号）
flag = true      // 布尔
nothing = nil    // 空值
x = 99           // 可以重新赋值
```

语句用 `;` 分隔。整个文件的最后一条表达式作为运行结果。

## 基本类型

- 数字：`42`、`3.14`
- 字符串：`'hi'`（只能单引号）
- 布尔：`true` / `false`
- 空值：`nil`

## 运算符

```ooc
1 + 2      // 3，数字加法；对字符串是拼接
7 - 3      // 4
6 * 4      // 24
7 % 3      // 1，取模
10 > 5     // true；>= <= < 同理
10 == 10   // true；!= 同理
1 && 0     // 0；|| 同理
```

注意：`//` 是注释符号，不是除法。

## 消息调用

一切都是消息，写法是 `接收者 消息名 参数...`：

```ooc
'abcdef' slice 1 3    // 'bc'，调用字符串方法
'abc' + 'def'         // 'abcdef'
```

消息名、参数之间用空格分隔，没有括号。

## JS 对象属性：用 `@`

自定义对象（`{ ... }`）只有方法、没有属性。JS 对象的**属性**要加 `@` 前缀访问：

```ooc
'abcdef' @length     // 6，读取 JS 属性
```

不带 `@` 时按方法调用，遇到属性会报错并提示改用 `@`。
